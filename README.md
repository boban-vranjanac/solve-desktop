# solve.rs za Mac i Windows

Instalacije aplikacije [solve.rs](https://invoice.solve.rs) za računar. Aplikacija je isti sajt invoice.solve.rs, uz jednu razliku: račune, predračune i ponude možeš da kucaš i štampaš i kad nema interneta. Kad se veza vrati, sami se upisuju na sajt i šalju na SEF ili mejlom.

Za rad je potreban nalog na invoice.solve.rs.

## Preuzimanje

| Računar | Instalacija |
|---|---|
| Mac sa Apple čipom (M1, M2, M3, M4) | [solve.rs-mac-apple-silicon.dmg](https://github.com/boban-vranjanac/solve-desktop/releases/latest/download/solve.rs-mac-apple-silicon.dmg) |
| Mac sa Intel procesorom | [solve.rs-mac-intel.dmg](https://github.com/boban-vranjanac/solve-desktop/releases/latest/download/solve.rs-mac-intel.dmg) |
| Windows 10 i 11 | [solve.rs-windows.exe](https://github.com/boban-vranjanac/solve-desktop/releases/latest/download/solve.rs-windows.exe) |

Ne znaš koji Mac imaš? Meni  → „O ovom Mac-u": piše „Chip Apple M…" ili „Processor Intel…".

## Prvo otvaranje

- **Mac:** prevuci solve.rs u Applications. Prvi put otvori desnim klikom → Otvori → Otvori.
- **Windows:** ako se pojavi „Windows je zaštitio računar", klikni „Više informacija" → „Ipak pokreni".

Sve verzije: [Releases](https://github.com/boban-vranjanac/solve-desktop/releases).
